# Personalized RAG 기반 공모전 Re-ranking 및 팀 매칭 서비스

숙명여자대학교 인공지능공학부 2026 졸업프로젝트 (팀 프로젝트)
원본 레포지토리: [Re-ranking/FE](https://github.com/Re-ranking/FE)

## 프로젝트 소개
사용자가 업로드한 CV를 분석해 역량에 맞는 공모전을 추천하고,
협업 성향과 부족한 역량을 고려해 함께할 팀원을 추천하는 웹 서비스입니다.

## 주요 기능
- CV 업로드 및 강점·약점 역량 분석
- 분야·기술 점수 기반 맞춤 공모전 추천
- 협업 성향 설문
- 성향 적합도와 역량 보완도 기반 팀원 추천

## 기술 스택
React · Vite · Axios · JWT · Vercel

## 담당 역할 (이연우 · Frontend)
- 서비스 전체 화면 구현
- Swagger 기반 API 연동
- JWT 인증 및 Axios 인터셉터 처리
- Vercel 배포

## 실행 방법
```bash
npm install
npm run dev
```
